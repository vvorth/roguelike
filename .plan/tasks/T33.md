# T33 — Species resistances
Status: todo
Depends on: T29 (`items.py` complete)

## Goal
Give each species a resistance profile, so a damage type means something.

## Context
An interactive terminal roguelike, ADOM-ish, standard library only. Versions 1–5 are complete
(2615 tests). Version 6 adds weapons with damage types; this task makes the bestiary care.

Three other workers are running in parallel on unrelated modules.

**Why this matters, measured:** with one species resisting the player's only damage type, floor
clears drop **45.6% → 8.5%**. That severity is deliberate — it is the pressure that makes
carrying a second weapon worth the pack space. The starting dagger is PIERCE and the cave snake
resists PIERCE precisely so the player meets that wall early.

Out of scope: applying resistance (that is `combat.py`, another worker), new species, changing
any existing stat, flee chances, spawn rules, AI behaviour. **Every existing number in
`npc.py` stays exactly as it is.**

- `roguelike/items.py` and `.plan/reports/T29.md` — complete; read, do not modify.

## Produce
`roguelike/npc.py`: `SpeciesData` gains a resistance profile, and a lookup so a caller can ask
"how does this species take SLASH?". Plus `tests/test_npc.py`.

**The shape is your decision** — a `dict[DamageType, Resistance]` per species with `NORMAL`
implied for anything absent is the obvious one, and a helper
`resistance_of(species, damage_type) -> Resistance` keeps callers from doing `.get(..., NORMAL)`
by hand. State whatever you choose prominently in your report; `combat.py`'s caller reads it.

## Constraints
- Python 3.10+, standard library only. `npc.py` may now import `roguelike.items`; it must
  still not import `combat`, `game`, `render`, `keys`, `events` or `curses`.
- Every dataclass stays frozen; every function stays pure.
- Derived stats are still **not** stored on `SpeciesData` — HP/speed/evasion/block come from
  `stats.derive` and nowhere else.
- **Do not change** any stat, attack range, xp value, poison chance, flee chance, glyph, name,
  hostility, or any spawn/AI constant.

## Acceptance criteria
- The §26.3 table asserted per species, per damage type — all four species × all three types.
- **Nothing is `IMMUNE`** — asserted, so the tier stays unused until something needs it.
- Anything not in the table reads `NORMAL`.
- **Regression:** every existing species number is unchanged. Assert the four stat blocks, the
  attack ranges, xp values, the cave snake's 30% poison, the flee chances (2/5/3/1), glyphs,
  names and `hostile=True` — the whole table, so a stray edit is loud.
- Derived values still come from `stats.derive`: rat 17/140/17/0, jackal 25/130/14/0, giant bat
  13/180/29/0, cave snake 25/80/0/0.
- `SpeciesData` still stores no derived value.
- Existing AI, spawn and flee tests all still pass unchanged.
- Import purity via `ast`.
