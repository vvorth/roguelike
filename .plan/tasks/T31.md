# T31 — Regeneration status effect
Status: todo
Depends on: none

## Goal
One new `StatusKind` that heals instead of harming, so a bandage can be an effect rather than
an instant.

## Context
An interactive terminal roguelike, ADOM-ish, standard library only. Versions 1–5 are complete
and passing **2615 tests**. Version 6 adds consumables: a potion heals instantly, a **bandage
heals over time** — and `status.py` already has exactly the right shape for that.

`StatusEffect` is a kind, a duration and a magnitude, ticked once per world-tick by
`tick_effects`, which today returns total *damage*. A regeneration effect is `POISONED` with
the sign flipped, and adding it makes `StatusKind` finally hold something that is not a
punishment.

Two other workers are running in parallel on unrelated leaf modules.

**Your module is a leaf and imports nothing from the project.**

Out of scope: applying the effect (the game loop does that), food, hunger, any other new
status kind, and the potion (an instant heal, not an effect). Extra surface is a defect.

## Read first
- `.plan/CONTRACT-v6.md` §25.1 (the bandage's numbers: `regen_turns=5, regen_magnitude=3`),
  §9 v6, §10 v6.
- `.plan/CONTRACT-v5.md` §22 — the existing status contract, all of it still binding.
- `roguelike/status.py` — the module you extend.

## Produce
`roguelike/status.py`: `StatusKind.REGENERATING`, and whatever `tick_effects` needs so a caller
can learn how much healing a tick produced as well as how much damage.

**The signature change is yours to design**, and this is the one real decision in the task.
`tick_effects` currently returns `(effects, damage)`. Options include returning
`(effects, damage, healing)`, or returning a signed net. **Recommendation: return a third
value rather than a signed net** — a net of zero is ambiguous between "nothing happened" and
"2 damage and 2 healing", and the game loop words those differently. Whatever you choose,
state it prominently in your report: `game.py`'s author reads only that.

Plus `tests/test_status.py`.

## Constraints
- Python 3.10+, standard library only. Imports nothing from `roguelike`. No `curses`.
- Frozen dataclasses, pure functions, integer arithmetic.
- **Every existing v5 behaviour of `apply_effect` and poison ticking is unchanged**, including
  refresh-not-stack and "an effect still deals its damage on the tick that removes it".
- `REGEN_TURNS` (natural healing, unrelated to bandages) keeps its value of 3.

## Acceptance criteria
- `StatusKind` has exactly `POISONED`, `ENRAGED`, `REGENERATING`.
- A `REGENERATING` effect produces healing per tick equal to its magnitude, for exactly
  `remaining_turns` ticks, and **still heals on the tick that removes it** — the same rule
  poison already follows.
- Poison and regeneration **coexist**: an actor with both gets both, and the caller can tell
  them apart.
- `apply_effect` refresh-not-stack still holds for the new kind: a longer duration replaces, a
  shorter or equal one does not, and there is never more than one entry per kind.
- Every v5 poison test still passes unchanged in meaning.
- `tick_effects(())` returns the empty case cleanly under the new signature.
- Purity: inputs never mutated.
- Import purity asserted with `ast`.
