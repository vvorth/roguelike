`roguelike/level.py` — `__all__ = ["Room", "Level", "freeze_grid", "blank_grid"]`
```python
@dataclass(frozen=True)
class Room:
    x: int; y: int; width: int; height: int      # positional order binding
    def __post_init__(self) -> None              # ValueError if width < 1 or height < 1
    @property
    def x2(self) -> int                          # x + width - 1
    @property
    def y2(self) -> int                          # y + height - 1
    @property
    def center(self) -> tuple[int, int]          # (x + width // 2, y + height // 2)
    def contains(self, x: int, y: int) -> bool
    def on_perimeter(self, x: int, y: int) -> bool
    def intersects(self, other: "Room", margin: int = 1) -> bool

@dataclass(frozen=True)
class Level:
    width: int
    height: int
    grid: tuple[tuple[Tile, ...], ...]           # grid[y][x]
    rooms: tuple[Room, ...]
    player_start: tuple[int, int]                # (x, y)
    seed: int
    def __post_init__(self) -> None              # ValueError on dims/grid/player_start
    def in_bounds(self, x: int, y: int) -> bool  # never raises
    def tile_at(self, x: int, y: int) -> Tile    # IndexError off-map, incl. negatives
    def is_walkable(self, x: int, y: int) -> bool  # False off-map, never raises

def freeze_grid(grid: list[list[Tile]]) -> tuple[tuple[Tile, ...], ...]
def blank_grid(width: int, height: int, fill: Tile = Tile.WALL) -> list[list[Tile]]
```

Assumptions made:
- **`intersects` formula.** The contract gives semantics, not a formula. I implemented it as
  "the two floor rects, each expanded by `margin` cells in every direction, overlap":
  `self.x - margin <= other.x2 + margin and other.x - margin <= self.x2 + margin` (and the
  same on `y`). This is the only reading that satisfies all the stated acceptance criteria
  simultaneously: `margin=0` reduces to strict rectangle overlap; `margin=1` is True for
  overlapping, touching (gap 0) and one-wall-apart (gap 1) rooms, and False at gap >= 2.
  Consequence for T02 (§3 G5): `not a.intersects(b)` with the default margin means the floor
  rects are at least **two** cells apart on some axis, which satisfies "at least one wall cell
  separates them" with room to spare. Symmetric by construction, and unit-tested as such over
  a room matrix at margins 0/1/2.
- **`on_perimeter` definition.** Implemented as "inside the rect grown by 1, but not
  `contains`", which makes mutual exclusivity with `contains` structural rather than a
  coincidence, and includes all four corners.
- **`freeze_grid` "non-positive dimensions" (§2.3).** Read as: raise `ValueError` if the grid
  has zero rows, or if any row has zero cells. It does *not* check rectangularity — that is
  `Level.__post_init__`'s job and duplicating it would change which error a caller sees.
- **`__post_init__` validation order on `Level`:** width, then height, then row count, then
  per-row width, then `player_start` bounds. First failure wins; all raise `ValueError`.
- **Malformed `player_start`.** The contract specifies exactly `in_bounds(*player_start)`, so
  I call precisely that and added no arity check. A `player_start` that is not a 2-tuple
  therefore raises `TypeError` from the unpacking, not `ValueError`. This case is not
  specified in the contract; I chose literal fidelity over inventing a rule.
- **No type-checking of `width`/`height`/`seed`.** §3.1 mandates `TypeError` for bad types
  only on `generate_level`; §2 mandates nothing of the sort for `Level`/`Room`, so I added no
  isinstance checks.
- `blank_grid` builds each row with a fresh comprehension, so rows are independent objects
  (asserted by `id()` in tests). `freeze_grid` produces a genuine snapshot — later mutation of
  the source list-of-lists cannot reach the frozen grid (also tested).

Open questions for integrator:
1. `intersects` boundary, for T02's benefit: with the default `margin=1`, two rooms whose
   floor rects are separated by exactly one wall cell **do** intersect (i.e. are rejected by
   G5). A generator that aims for shared-wall room packing will find every candidate rejected;
   the minimum legal separation between floor rects is two cells. This follows directly from
   the brief's acceptance criteria, but it is the one place where the contract's prose
   ("sharing a wall") and a generator author's instinct could pull apart.
2. `Room` places no upper bound on coordinates and no relationship to any `Level` — a `Room`
   can be constructed entirely outside the level it is stored in. §3 G6 makes that T02's
   invariant to maintain; the type does not enforce it, by design.
3. Nothing in `roguelike/__init__.py` was changed, so `roguelike.tiles` / `roguelike.level`
   must be imported by full path. If the orchestrator wants re-exports at package level, that
