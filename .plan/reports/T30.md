## `roguelike/keys.py`

- Added `CommandKind.INVENTORY` (`"i"`) and `CommandKind.PICK_UP` (`"g"`) to `_NO_ARG_BINDINGS`,
  both with `dx == dy == 0` by construction (they go through the same `Command(kind)` path as
  every other no-arg binding).
- Added two `HELP_ENTRIES` rows: `("g", "pick up an item from a chest")` and
  `("i", "open your inventory")`.
- **Deliberately did NOT add "e", "d" or "t" to any binding table.** Per CONTRACT-v6 §5 these
  are live raw keys inside the inventory screen (equip / drop / item-slot letter), read exactly
  as direction keys are read raw inside look mode; binding them globally would break that
  screen. Verified with `translate_key("e"/"d"/"t") is UNKNOWN` in both the interactive check
  above and a dedicated test (`test_e_d_t_remain_unknown`, marked CRITICAL in a comment).
- Updated the module comments (docstring "fifteen things", the `_NO_ARG_BINDINGS` block comment)
  to describe the v6 additions and the e/d/t exclusion, matching the existing pattern for how
  earlier version bumps were documented in this file.
