- Test levels for both test files construct `Level` directly with hand-written grids
  (`CHAR_TO_TILE` mapping `'+' -> Tile.DOOR`, open/closed determined solely by the `open_doors`
  set passed alongside, never by a second tile value), per the brief's explicit instruction not
  to import the generator.

  consulted to decide what extra detail (if any) to attach to an already-rejected move. This
  matches CONTRACT-v2 §6 ("passability is now decided by world.is_passable... If the target is
  a closed door, return blocked_by_door=...").
